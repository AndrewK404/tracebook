How to use these.

Click any card to open the mockup. Each file is fully self-contained and works without the FastAPI daemon — useful for design review, screenshot capture, and stakeholder sharing.

When a mockup feels right, port it into the matching Jinja template under leibniz/templates/ and wire up real data. The class names and structure should transfer 1:1.

preview locally → open leibniz-platform/design/index.html
